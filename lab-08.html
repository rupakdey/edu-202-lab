Configure Cloud Applications Monitoring

Create repeatable ZDX monitoring for a custom cloud application. You will define the target population, create a Mail Server application, and attach both Web and Cloud Path probes.

3 tasksApprox. 20 minutes
Lab objectives

What you will accomplish

  • Configure a custom application in your Experience Center tenant to monitor a business-critical SaaS destination used by remote users.
  • Provision a Web probe for the custom application to measure application availability and web transaction performance.
  • Provision a Cloud Path probe for the same custom application to measure network-path health (latency, loss, and jitter).
8.1

Add an End User Collection

Define which users and devices will run the custom probes.

  1. On Corp: Client PC 1, sign in to the Experience Center with your assigned tenant account.
  2. Open ZDX End User probe collections.
    Search menu → End User
  1. Select Add and create an End User Collection named Custom Application.
  2. Leave all Exclusion Criteria as None.
  3. Set all Probing Criteria to All: User Groups, Users, Location Groups, Zscaler Locations, Departments, and Devices. Select Add.
  1. Confirm Custom Application appears in the End User Collections list.
✓
Expected result

The Custom Application End User Collection targets all users/devices with no exclusions.

8.2

Create a Custom Application

Create the Mail Server application that the probes will monitor.

  1. Open the Custom Application collection from Task 8.1 and select Add Application.
  1. Create the application:
    SettingValue
    NameMail Server
    StatusDisabled
    Application TypeCustom
    Select Add.
  1. Confirm Mail Server is listed under the collection.
✓
Expected result

The disabled Mail Server custom application exists and is ready for probe configuration.

8.3

Create Custom Probes

Add Web and Cloud Path probes to measure application and network experience.

  1. Under Mail Server, select Add Probe → End User Web, then select Next.
  2. Configure the Web probe:
    SettingValue
    NameMail Server_Web
    ApplicationMail Server
    Run Frequency5 minutes
    Probing CriteriaAll users, groups, locations, location groups, departments, devices
    Exclusion CriteriaNone
    Destination URLhttps://mail.google.com
    Number of Attempts2
    Timeout60 seconds
    Follow RedirectEnabled
    Maximum Redirects5
    Continue through the wizard.
  1. Review the Web probe and select Submit.
  2. Edit the Mail Server application, set Status = Enabled, and select Update. ZDX enables the associated Web probe automatically.
i
Metrics can take time

Depending on the ZDX plan and environment, a newly enabled application can take roughly 15–30 minutes before metrics appear. Continue with the lab and return later if needed.

  1. Add a second probe: Add Probe → End User Cloud Path.
  2. Configure the Cloud Path probe:
    SettingValue
    NameMail Server_Cloud
    StatusEnabled
    ApplicationMail Server
    Probe TypeCloud Path
    Follow Web ProbeMail Server_Web
    Run Frequency5 minutes
    Probing CriteriaAll
    Exclusion CriteriaNone
    ProtocolICMP
    Packet Count5
    Interval1000 ms
    Timeout1000 ms
    Cloud Path Hostmail.google.com
  1. Review and select Submit. Confirm both Mail Server_Web and Mail Server_Cloud appear under Mail Server.
✓
Expected result

Mail Server has an enabled Web probe and Cloud Path probe, providing application and network-path monitoring.

✓
