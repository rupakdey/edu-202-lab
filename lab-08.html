Lab 8 · Hands-on

Configure ZDX Alerts and Diagnostics

Create a threshold-based alert for Mail Server and run a five-minute Deep Tracing session.

2 tasks Approx. 15 minutes Dedicated tenant
Lab objectives

What you will accomplish

  • Configure application alert thresholds and notification settings.
  • Check hostname collection when diagnostics are unavailable.
  • Run Deep Tracing and inspect the completed report.
8.1

Create the Mail Server Alert Rule

Configure the source lab’s alert thresholds.

Search Menu → Alerts Overview
Zscaler Help: Alerts Overview ↗
  1. Sign in to Zscaler Client Connector on Corp Client PC 1 with the student account. In the Experience Center open Alerts Overview → Alert Rules and Templates, then Add Alert Rule.
    SettingValue
    Namealert_mailserver
    StatusEnabled
    TypeApplication
    SeverityMedium
  2. On Filters, choose Mail Server and its Mail Server_Web probe. Add a Geolocation filter and choose the relevant region (the source example is Asia → India).
  3. Set the criteria, then continue to Actions.
    SettingValue
    Page Fetch Time> 800 ms
    ZDX Score< 50
  4. Configure notification settings, review, and Save.
    SettingValue
    Alert Only if Repeated2
    Number of Active Devices1
    Alert Delivery MethodEmail
    Alert recipientUse an instructor-approved test address; example: learner@example.com
  5. Confirm alert_mailserver is listed. The rule need not trigger during the session; an example.com placeholder will not deliver a real email.
✓
Expected result

alert_mailserver is saved with the configured application, region, thresholds and action settings; no alert delivery is claimed unless a real qualifying event is observed.

8.2

Run a Diagnostic Session

Capture a five-minute view of the student device and probes.

Search Menu → Diagnostics
Zscaler Help: Diagnostics ↗
  1. Select Start New Diagnostic Session. If unavailable, search User Privacy, enable Collect Machine Hostname Information, Save, refresh and return to Diagnostics.
  2. Configure the session and select Next.
    SettingValue
    Namediagnostics_session_student<StudentID> (example: diagnostics_session_student000205)
    UserYour student administrator user
    DeviceThe enrolled device for that user
    Mode / DurationDeep Tracing / 5 minutes
  3. Choose Mail Server with Mail Server_Web and Mail Server_Cloud. Set Packet Loss = 20% and Latency = 10 ms, then Save.
  4. Find the session in the progress table. After five minutes, return to History and select View for the completed session. Review the application, device and path results.
✓
Expected result

The diagnostic session completes and its report shows the selected student device, Web probe and Cloud Path data where available.

✓
Lab 8 complete

You have completed the activities defined for Configure ZDX Alerts and Diagnostics.
