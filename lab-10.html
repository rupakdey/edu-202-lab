Analyze Data, Reports and Snapshots

Switch to SDC to explore existing ZDX data, review reports and open view-only snapshots.

3 tasks Approx. 15 minutes Read-only SDC
Lab objectives

What you will accomplish

  • Run and inspect a Data Explorer query.
  • Review an available QBR PowerPoint report.
  • Inspect predefined reports and view an existing ZDX Snapshot.
10.1

Analyze Data Explorer

Build a view of application and network performance.

i
Switch to SDC before this task

Complete the SDC access checkpoint. Use the SDC administrator identity from CloudShare Credentials, not your dedicated learner tenant.

Search Menu → Data Explorer
Zscaler Help: Data Explorer ↗
  1. Open Data Explorer and review the configured views. Select an existing View to open it.
  2. Use the left panel to choose the query options, then select Run Query.
    SettingValue
    Data Source / ProbesSelect the available application/probe data for the exercise
    Metrics / FiltersChoose the performance measures and scope to inspect
    Operations / View Type / OverlaysUse the options available in the selected view
  3. Review the resulting charts. Drag across a section to zoom into its time range and compare the application/metric details.
✓
Expected result

An available query runs and its charts support inspection of the selected application/network metrics and time range.

10.2

Review a QBR Report

Download an existing report and review the trends.

  1. Use Search Menu → ZDX QBR Reports or open the corresponding reports page. Review the available reporting periods.
  2. Select the report’s Download icon. Open the PowerPoint file and review its user-experience trends.
i
Use an existing report

The source notes reports are generated on the first weekend of the month. Availability depends on the SDC tenant and reporting period; this task does not require generating a new report.

✓
Expected result

You can open an available QBR report and identify trends in the existing ZDX data.

10.3

Review Reports and Open a Snapshot

Inspect system reports and a view-only shared snapshot.

  1. Use Search Menu → Predefined Reports. Select View for an available report such as Cloud Path End-to-End.
  2. Filter by Departments, Zscaler Locations, Geolocations or Applications. Select a chart point for latency details; drag to zoom and use Zoom Out to reset.
  3. Use Search Menu → ZDX Snapshots. For an active snapshot, select Copy and open the copied link in a new browser window.
  4. Confirm the green snapshot indicator. Compare the allowed interactions with the live page: time range, device/application selection and detailed metrics may be fixed or unavailable.
i
Read-only SDC task

Although the source task heading mentions generating snapshots, its steps open an existing active snapshot. This guide follows those executable steps; creating a new snapshot requires suitable permissions.

✓
Expected result

The report responds to available filters and an existing snapshot opens with the view-only indicator and expected interaction limits.

✓
Lab 10 complete

You have completed the activities defined for Analyze Data, Reports and Snapshots.
