Automation Using Zscaler APIs

Use Postman and Zscaler OneAPI to authenticate with OAuth 2.0, test API access, and programmatically create a ZPA App Connector Group.

5 tasksApprox. 20 Minutes
Lab objectives

What you will accomplish

  • Access Postman to prepare for API testing.
  • Import the Zscaler OneAPI Postman collection.
  • Gather the required variables for OneAPI authentication (for example, base URL, client ID, client secret, and
  • customer ID).
  • Authenticate and Test OneAPI Endpoints in POSTMAN and verify connectivity by running OneAPI requests.
  • Create an App Connector Group via the OneAPI management endpoint to automate ZPA infrastructure setup.
10.1

Access Postman to Call an API

Open Postman and prepare the client used for OneAPI requests.

  1. Use the pre-installed Postman on Corp: Client PC 1, or open https://www.postman.com/ in a browser.
  2. Create a free Postman account or sign in to an existing account.
✓
Expected result

Postman is open and ready to import the Zscaler OneAPI collection.

10.2

Import the OneAPI Collection into Postman

Load the current Zscaler OneAPI request collection.

  1. Open https://automate.zscaler.com/docs/tools/postman/adding-oneapi-postman-collection and download the latest Zscaler OneAPI Postman collection.
  1. In Postman, use File → Import and import the downloaded collection.
  1. Confirm the Zscaler OneAPI collection appears in the Collections pane.
✓
Expected result

The OneAPI collection is imported and visible in Postman.

10.3

Gather Variables for OneAPI Authentication

Collect the tenant and OAuth values needed by Postman.

  1. Obtain the Authentication Service base URL. Open the Service Portal / Authentication Service from the Experience Center and copy the tenant base URL shown in the browser address.
    Search menu → Service Portal
  1. Create a OneAPI client. Open API Clients, select Add API Client, and configure:
    Search menu → API Clients
    SettingValue
    NameTestClient
    StatusEnabled
    Access Token Validity90 Minutes
    Validation TypeSecret
    Add the client.
!
Save the client secret now

The generated secret is shown only at creation time. Copy it to a temporary local text file before saving the API client.

  1. On Resources, assign the roles required by the source lab: Super Admin for ZCC and ZIA, and API Full Access for ZPA. Save the client and record its Client ID.
  1. Obtain the ZPA Customer ID from Linked Services; locate the ZPA Tenant ID / Customer ID and record it.
    Search menu → Linked Services
✓
Expected result

You have the four values required by the next task: Authentication Service base URL, Client ID, Client Secret, and ZPA Customer ID.

10.4

Authenticate and Test OneAPI Endpoints

Obtain a token and verify successful API requests.

  1. In Postman, select the OneAPI collection and open Variables. Populate:
    SettingValue
    authServiceBaseUrlAuthentication Service base URL from Task 10.3
    clientSecretGenerated client secret
    clientIDGenerated Client ID
    customeridZPA Customer ID
  1. Select Get New Access Token, then select Use Token in Manage Access Tokens.
  1. In the Experience Center, open OneAPI Tokens and verify a recently issued token for your Client ID.
    Search menu → Tokens
  2. In Postman, run Zscaler Client Connector → Get All Enrolled Devices. Select Send and confirm HTTP 200 OK. Then run Download device details as a CSV file and confirm the response succeeds.
✓
Expected result

Postman authenticates successfully and OneAPI requests return successful responses.

10.5

Create an App Connector Group with OneAPI

Use the ZPA OneAPI endpoint to create and verify a new connector group.

  1. In the Experience Center, review the existing App Connector Groups so you can later confirm the API-created group is new.
    Search menu → App Connector Groups
  2. In Postman, open ZPA → Enrollment Certificate Controller → Get all configured enrollment certificate details for the specific customer and select Send.
  1. In the response body, locate the certificate Id. You will use this value as signingCertId.
  1. Open ZPA → Connector Group Controller → Add a new App Connector Group for Specified Customer.
  2. In the request body, use the following payload and replace signingCertId with the ID obtained above:
    { "name": "ZPALAB APPC Group", "description": "App Connector training Lab at San Jose", "latitude": "37.3382032", "longitude": "-121.886286", "location": "San Jose, CA, USA", "signingCertId": "7651" }
  3. Ensure the API client is active and the access token has not expired. Select Send and confirm HTTP 201 Created.
  1. Return to App Connector Groups in the Experience Center and confirm ZPALAB APPC Group exists.
✓
Expected result

OneAPI creates ZPALAB APPC Group, and the group is visible in the ZPA App Connector Groups list.

✓
