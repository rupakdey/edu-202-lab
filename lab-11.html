Lab 11 · Solutions Demo Center

Analyze Data and View Integrated Reports and Snapshots

Use the pre-populated Solutions Demo Center to analyze ZDX data and reporting. You will explore Data Explorer, download a QBR report, interact with system-generated reports, and open a shareable ZDX Snapshot.

3 tasksApprox. 15 MinutesRead-only SDC
Lab objectives

What you will accomplish

  • Analyze user experience and performance data using Data Explorer.
  • Download and review QBR reports for trend insights.
  • Review system-generated reports and create ZDX Snapshots to share view-only findings.
11.1

Analyze Data Explorer for Application and Network Performance

Build a query and inspect the resulting application and network metrics.

  1. Using the SDC administrator session, open ZDX Data Explorer. If prompted, enable Switch to Existing Reports.
    Search menu → Data Explorer
  1. Select View and build a custom view by choosing the data source, probes, metrics, filters, operations, view type, and overlays you want to analyze. Select Run Query.
  1. Review the resulting application/network charts. Drag across a chart to zoom into a specific time range and inspect the details.
✓
Expected result

You can create a Data Explorer view, run a query, and inspect application/network performance over a selected time range.

11.2

View QBR Reports for ZDX User Insights

Download and review an existing Quarterly Business Review report.

  1. Open Quarterly Business Reviews in ZDX and review the available reports.
    Search menu → Quarterly Business Reviews
  1. Select the Download icon for a report, open the downloaded PowerPoint, and review the report contents.
i
QBR generation

The source guide notes that a new QBR report is generated on the first weekend of each month and stored as a PowerPoint file in the Zscaler cloud.

✓
Expected result

You can download and review a pre-generated ZDX QBR report.

11.3

View Integrated Reports and Generate Snapshots

Explore system-generated reports and share a view-only Snapshot.

  1. Open System Generated Reports and select the View icon for a report.
    Search menu → System Generated Reports
  1. For a Cloud Path End-to-End report, experiment with available filters such as Departments, Zscaler Locations, Geolocations, or Applications. Select graph points to view latency tooltips, drag across a range to zoom, and use Zoom Out to reset.
  1. Open ZDX Snapshots, copy the link for an active snapshot, and paste it into a new browser window.
    Search menu → ZDX Snapshots
  1. Confirm the snapshot opens with the green Snapshot indicator. Snapshot pages provide view-only sharing with some interactive controls disabled.
✓
Expected result

You can interact with system-generated reports and open a view-only ZDX Snapshot through its shareable link.

✓
Lab 11 complete

You have completed the activities defined for Analyze Data and View Integrated Reports and Snapshots.
