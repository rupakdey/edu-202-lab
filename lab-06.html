Configure Browser Isolation for ZPA

Apply a render-only profile to DVWA and compare user actions before and after isolation.

3 tasks Approx. 20 minutes Dedicated tenant
Lab objectives

What you will accomplish

  • Create a render-only isolation profile.
  • Apply the profile to the DVWA application segment.
  • Compare clipboard, upload/download and printing behavior.
6.1

Create the Render-Only Profile

Keep the application viewable while restricting data actions.

i
Capture the baseline first

Before applying isolation, open the DVWA External Domain and try copy/paste and a harmless training-file upload. Record what works. After Task 6.2, repeat the same actions in a fresh session.

Search Menu → Isolation Profile
Zscaler Help: Isolation Profile ↗
  1. Select Add and name the profile render_only_profile. Select Next.
  2. Leave Company Settings at defaults. In the security/settings page, enable View Office Files in Isolation only. Keep download, upload, copy/paste and printing disabled for this render-only exercise.
  3. Select all Regions, then Next. Leave the isolation banner at defaults; watermarks are optional. Review and Save.
✓
Expected result

render_only_profile is saved with view-only interaction settings.

6.2

Apply the Isolation Policy

Match the DVWA application segment.

Search Menu → Isolation Policy
Zscaler Help: Isolation Policy ↗
  1. Select Add Rule and configure the rule.
    SettingValue
    Nameisolate_policy_render_only
    Rule ActionAllow Isolation, where the UI requires an action
    Isolation Profilerender_only_profile
    Applications criterionDVWA
  2. Select Add Rule and confirm the profile and DVWA segment are associated.
✓
Expected result

The isolation policy targets DVWA with render_only_profile.

6.3

Verify Render-Only Behavior

Repeat the baseline actions through an isolated session.

  1. Disconnect/log out of Zscaler Client Connector. Open a fresh tab to https://<DVWA-External-Domain>; copy that domain from Browser Access if needed. Authenticate to the lab identity service and DVWA.
  2. Confirm the browser displays the isolation banner. Repeat the copy/paste, upload, download and printing actions you checked before Task 6.1.
  3. Confirm the application remains viewable while the configured data actions are unavailable. Compare the results with your baseline; an upload may also be affected by the AppProtection Block policy from Lab 5, so use clipboard/printing behavior and the isolation banner to distinguish the controls.
✓
Expected result

DVWA opens in isolation and the configured render-only restrictions apply to a new browser session.

✓
