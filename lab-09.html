Zscaler Digital Experience — Configure Alerts & Diagnostics

Use ZDX to detect and investigate degraded user experience. You will create an application alert with thresholds, then run a five-minute diagnostic session with Deep Tracing and the Mail Server probes.

2 tasksApprox. 15 minutes
Lab objectives

What you will accomplish

  • Configure ZDX alerting in your Experience Center tenant to detect user experience degradation (e.g. Page Fetch Time, ZDX score) for a business-critical application.
  • Validate that the alert rule and ZDX Diagnostics Session report provide actionable evidence for NOC troubleshooting/escalation
9.1

Create an Alert Rule

Alert when Mail Server experience crosses the defined thresholds.

  1. On Corp: Client PC 1, sign in to Zscaler Client Connector with your assigned student account.
  2. Open ZDX Alerts and select Alert Rules and Templates.
    Search menu → Alerts
  1. Select Add Alert Rule and configure:
    SettingValue
    Namealert_mailserver
    StatusEnabled
    TypeApplication
    SeverityMedium
    Select Next.
  2. On Filters, select the Mail Server application and its probe. Add a Geolocation filter and choose a region in Asia (for example, India).
  1. Set the alert criteria and actions:
    SettingValue
    Page Fetch Time> 800 ms
    ZDX Score< 50
    Alert Only if Repeated2
    Number of Active Devices1
    Delivery MethodEmail
    RecipientAny dummy email address for the lab
    Continue to Review.
  1. Review and save the rule. Confirm alert_mailserver appears in the alert-rule list.
✓
Expected result

The enabled alert_mailserver rule monitors Mail Server experience against the defined thresholds.

9.2

Configure a Diagnostic Session

Capture focused device, application, and network telemetry for troubleshooting.

  1. Open ZDX Diagnostics and select Start New Diagnostic Session.
    Search menu → Diagnostics
i
If Start New Diagnostic Session is missing

Open Client Connector User Privacy, enable Collect Machine Hostname Information, refresh, and return to Diagnostics.

  1. Create the session:
    SettingValue
    Namediagnostics_session_student<StudentID>
    UserYour assigned Student Admin user
    DeviceSelect that user’s device
    TracingDeep Tracing
    Duration5 minutes
    Select Next.
  1. Select Mail Server, then select Mail Server_Web and Mail Server_Cloud. Under Cloud Path thresholds, set Packet Loss = 20% and Latency = 10 ms. Select Save.
  1. Confirm the session appears in the progress table. Continue to the next lab; after approximately five minutes, return to Diagnostics, locate the completed session in History, and open its report.
✓
Expected result

A completed diagnostics report is available for the selected student device and Mail Server probes.

✓
