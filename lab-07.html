Lab 7 · Hands-on

Zero Trust Browser ZPA

Apply ZPA Browser Isolation to the DVWA private application. You will build a render-only profile, target DVWA with an isolation policy, and compare user behavior before and after isolation.

3 tasks
Lab objectives

What you will accomplish

  • Create an Isolation Profile configured for render-only access.
  • Create an Isolation Policy that applies the profile to a specific application segment.
  • Validate that users can view content in isolation, but cannot perform restricted actions.
7.1

Create the Isolation Profile

Build the render-only isolation profile used for the private application.

i
Before you isolate DVWA

Open DVWA once before applying the isolation policy and note that copy/paste and file upload work normally. You will repeat the same actions after isolation is enabled.

  1. Open the Private Access Browser Isolation Profiles page and select Add.
    Search menu → Isolation profile
  2. Set Name = render_only_profile and continue. ZPA isolation profile names cannot include special characters and cannot duplicate ZIA isolation profile names.
  1. On Company Settings, leave the defaults.
  2. On the render-only settings page, enable View Office Files in Isolation only.
  1. On Regions, select all regions and continue.
  2. On the Isolation Banner page, leave the defaults. Watermarking is optional.
  1. Review the profile, select Save, and confirm render_only_profile appears in the profile list.
✓
Expected result

The render_only_profile is ready to apply to a private application.

7.2

Create the Isolation Policy

Apply the render-only profile to the DVWA application.

  1. Open Isolation Policy for Private Access and select Add.
    Search menu → Isolation Policy
  1. Configure:
    SettingValue
    Policy Nameisolate_policy_render_only
    Isolation Profilerender_only_profile
    Application criteriaSelect the DVWA application segment
    Select Save.
  1. Confirm isolate_policy_render_only appears in the policy list with DVWA in its criteria.
✓
Expected result

DVWA is targeted by the render-only ZPA isolation policy.

7.3

Test and Verify

Confirm that DVWA remains viewable while restricted actions are blocked.

  1. Disconnect from Zscaler Client Connector to simulate a third-party browser-only user.
  2. Open DVWA using either dvwa.patraining.safemarch.com or the DVWA External Domain from Browser Access. Authenticate through the IdP if prompted.
    Search menu → Browser Access
  1. Sign in to DVWA and repeat the actions you tested before isolation: copy/paste text and attempt a file upload/download or print action.
  2. Confirm the application remains viewable, but restricted actions such as download, upload, copy, paste, and print are unavailable.
✓
Expected result

DVWA opens through Browser Isolation and is usable for viewing, while the configured data-transfer actions are restricted.

✓
Lab 7 complete

You have completed the activities defined for Zero Trust Browser ZPA.
