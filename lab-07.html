Configure Cloud Application Monitoring

Create a ZDX end-user collection and Mail Server application with Web and Cloud Path probes.

3 tasks Approx. 20 minutes Dedicated tenant
Lab objectives

What you will accomplish

  • Create the Custom Application end-user collection.
  • Monitor mail.google.com using Web and Cloud Path probes.
  • Enable the application and allow time for metrics to arrive.
7.1

Create the End-User Collection

Choose the users and devices that will run the probes.

Search Menu → Probes
Zscaler Help: Probes ↗
  1. In the end-user collection area, select Add. Configure the collection.
    SettingValue
    NameCustom Application
    Exclusion CriteriaUser Groups, Users, Location Groups, Zscaler Locations, Departments and Devices: None
    Probing CriteriaUser Groups, Users, Location Groups, Zscaler Locations, Departments and Devices: All
  2. Select Add and verify Custom Application appears.
✓
Expected result

Custom Application exists with the source lab’s all-user probing scope and no exclusions.

7.2

Create the Mail Server Application

Add a custom application before configuring its probes.

  1. Open the Custom Application collection and select Add Application.
  2. Configure the application and select Add.
    SettingValue
    NameMail Server
    StatusDisabled initially
    Application TypeCustom
  3. Verify Mail Server appears under the collection. Keep it disabled until the Web probe is created in Task 7.3.
✓
Expected result

Mail Server is listed under Custom Application, ready for probe configuration.

7.3

Create Web and Cloud Path Probes

Measure the web transaction and its network path.

  1. Under Mail Server, select Add Probe → End User Web → Next.
    SettingValue
    NameMail Server_Web
    ApplicationMail Server
    Run Frequency5 minutes
    Destination URLhttps://mail.google.com
    Probing CriteriaUsers, User Groups, Locations, Location Groups, Departments, OS: All
    Exclusion CriteriaSame fields: None
    Number of Attempts2
    Timeout60 seconds
    Follow Redirect / Maximum redirectEnabled / 5
  2. Review and Submit. Edit Mail Server, set Status → Enabled, then Update.
  3. Select Add Probe → End User Cloud Path → Next.
    SettingValue
    NameMail Server_Cloud
    Status / ApplicationEnabled / Mail Server
    Probe TypeCloud Path
    Follow Web ProbeMail Server_Web
    Run Frequency5 minutes
    Cloud Path Hostmail.google.com
    Probing CriteriaUsers, User Groups, Locations, Location Groups, Departments, Devices: All
    Exclusion CriteriaSame fields: None
    ProtocolICMP
    Packet Count5
    Interval / Timeout1000 ms / 1000 ms
  4. Review and Submit. Confirm both probes appear under Mail Server.
i
Metrics are not immediate

The source allows 15–30 minutes for a new application’s metrics, depending on the ZDX plan. Keep ZCC enrolled and connected for user/device data. Continue to Lab 8 and return later to review results.

✓
Expected result

Mail Server is enabled with Mail Server_Web and Mail Server_Cloud at five-minute intervals; metrics appear after eligible devices run the probes.

✓
Lab 7 complete

You have completed the activities defined for Configure Cloud Application Monitoring.
