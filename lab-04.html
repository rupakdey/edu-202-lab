Lab 4 · Hands-on

Zero Trust Browser ZIA

Use Browser Isolation to make social-networking access view-only, then create a granular Cloud App Control exception so LinkedIn is allowed normally while other matching sites remain isolated.

3 tasksApprox. 20 Minutes
Lab objectives

What you will accomplish

  • Create an Isolation Profile that allows view-only access (no download, upload, copy, or paste).
  • Configure a URL Filtering rule that isolates selected Social Networking URL categories.
  • Create a granular Cloud App Control policy that allows LinkedIn to bypass isolation while other social
  • networking sites remain isolated.
  • Verify isolation behavior by testing access to social networking sites (for example, x.com, instagram.com,
  • linkedin.com, and facebook.com).
4.1

Build an Isolation Profile

Define the user restrictions and isolation experience.

  1. Open the Internet & SaaS Isolation Profiles page and select Add Profile.
    Search menu → Isolation profile
  2. Configure:
    SettingValue
    Nameisolate_profile-social_networking-internet
    DescriptionIsolate Social Networking Sites to view only
    Other General settingsLeave at default
    Select Next.
  3. On Company Settings, keep the defaults and continue.
  1. On Security, enable Original URL. Leave the remaining settings at default and select Next.
  1. On Regions, select any two regions close to the user and continue.
  2. On Isolation Experience, enable Watermarking and choose a preferred Date & Timestamp. Leave the other settings at default.
  1. Review the profile and select Save.
✓
Expected result

The isolate_profile-social_networking-internet profile is available for policy use.

4.2

Implement an Isolation Policy

Apply Browser Isolation to Social Networking URL categories.

  1. Open URL Filtering and select Add URL Filtering Rule. In the new Experience Center, the direct path is Internet Access → Policy → URL Filtering.
    Search menu → URL Filtering
  1. Configure the rule:
    SettingValue
    Rule Order1
    Rule Nameisolate-outbound-socialsite
    URL CategoriesSocial Networking; Social Networking Adult
    ProtocolsHTTP, HTTPS
    User AgentsChrome, Firefox, Microsoft Edge, Microsoft Internet Explorer, Safari
    Web Traffic ActionIsolate
    Isolation Profileisolate_profile-social_networking-internet
    Save the rule and Activate the changes.
  1. Verify Zscaler Client Connector is signed in, then open x.com, instagram.com, linkedin.com, and facebook.com. Incognito mode can make the test easier to repeat.
  2. Confirm each site opens in an isolated session. If the watermark is not obvious, check the isolation URL / browser-isolation indicators.
✓
Expected result

The selected Social Networking categories open through Browser Isolation using the new isolation profile.

4.3

Add a Cloud App Policy Exception

Allow LinkedIn without removing isolation from other social-networking sites.

  1. Open Cloud App Policy and add a Social Networking rule.
    Search menu → Cloud App Policy
  1. Configure the exception:
    SettingValue
    Rule Order1
    Rule Nameallow-outbound-linkedin-any
    Cloud ApplicationLinkedIn
    ViewingAllow
    DescriptionNot isolating the LinkedIn Social Networking Site
    Save and Activate the change.
  1. Open linkedin.com and confirm it is allowed without isolation.
  2. Open the other social-networking sites again and confirm they remain isolated.
✓
Expected result

LinkedIn is allowed normally while the broader social-networking categories continue to be isolated.
