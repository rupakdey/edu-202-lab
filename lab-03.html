Configure Log Streaming

Send ZPA user-activity logs through a dedicated connector to the lab syslog receiver, then verify the live feed.

4 tasks Approx. 20 minutes Dedicated tenant
Lab objectives

What you will accomplish

  • Enroll a dedicated Log Streaming connector.
  • Create a TCP 514 log receiver for User Activity.
  • Allow SSH to SIEM and verify incoming zpa-lss records.
3.1

Enroll the Log Streaming Connector

Use a separate connector group for log delivery.

Infrastructure›Private Access›Component›App Connector Groups

Documented route; portal menu versions can differ. Search by the feature name if needed.

Search Menu → App Connector Groups
Zscaler Help: App Connector Groups ↗
  1. Create an enabled group named Log Streaming. Use the Connector signing certificate and appropriate location, as in Task 2.1.
  2. Open Corp Log Streaming Connector in CloudShare and sign in as admin / Zscaler1!. Read its enrollment token.
    cat /etc/issue
  3. Only if a new token is required, reset this training VM’s connector state.
    !
    Destructive enrollment reset

    Run the following only on Corp Log Streaming Connector when re-enrollment is necessary; it clears the VM’s connector state.

    sudo systemctl stop zpa-connector
sudo su
rm -rf /opt/zscaler/var/*
systemctl start zpa-connector
cat /etc/issue
exit
  4. Open App Connectors, select Add, choose Log Streaming, and add the current token. Save and verify Connection Health becomes Connected.
✓
Expected result

A connected App Connector is associated with the Log Streaming group, separate from OnPrem.

3.2

Add the Log Receiver

Stream User Activity records to the SIEM syslog service.

Search Menu → Log Receivers
Zscaler Help: Log Receivers ↗
  1. Select Add and configure the receiver.
    SettingValue
    NameSyslog-UserActivity
    Domain or IP Addresssiem.patraining.safemarch.com
    TCP Port514
    App Connector GroupsLog Streaming
  2. Select Next and configure the log stream.
    SettingValue
    Log TypeUser Activity
    Log TemplateCSV
    Log Stream ContentLeave at defaults
  3. Leave optional filters unchanged unless the instructor specifies otherwise. Review and Save.
✓
Expected result

Syslog-UserActivity is saved with TCP 514, User Activity/CSV, and the Log Streaming connector group.

3.3

Allow SSH to SIEM

Create the application and policy used to inspect the receiver.

Policies›Access Control›Private Applications›Defined Application Segments

Documented route; portal menu versions can differ. Search by the feature name if needed.

Search Menu → Application Segments
Zscaler Help: Application Segments ↗
  1. Add an application segment with the following settings.
    SettingValue
    NameSSH to SIEM
    Applicationssiem.patraining.safemarch.com
    Default Port RangesSSH · TCP 22
    Segment GroupCorpApps
    Server GroupCorpServers (the group created in Task 2.3)
  2. Review and Save. Select Edit Policy and add an Allow Access rule for SSH to SIEM and your student user. Save the rule.
✓
Expected result

The student user is allowed to reach the SIEM application over SSH through ZPA.

3.4

Verify the Live Log Feed

Generate activity and confirm records arrive on the receiver.

  1. On Corp Client PC 1, open Zscaler Client Connector from the Windows tray and sign in with the student tenant account. Confirm Internet Security and Private Access are available and connected.
  2. Open Command Prompt and connect to the SIEM host. Confirm the host key belongs to the lab before accepting it; enter Zscaler123! when prompted.
    ssh zscaler@siem.patraining.safemarch.com
  3. Watch the syslog file.
    tail -f /var/log/syslog
    Refresh HVAC from the remote browser if needed to generate activity. Look for recent User Activity / zpa-lss entries.
  4. Use Ctrl+C to stop tail, then run exit to close SSH.
✓
Expected result

Recent ZPA user-activity records arrive on the lab SIEM and correlate with the activity you generated.

✓
