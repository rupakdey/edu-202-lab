Lab 3 · Hands-on

Configure Log Streaming

Stream private-application activity to the on-premises SIEM. You will provision a dedicated connector, define the log receiver, enable SSH access for verification, and confirm live User Activity events.

4 tasksApprox. 20 minutes
Lab objectives

What you will accomplish

  • Provision a dedicated App Connector to establish a high-performance path for log traffic.
  • Configure a log receiver to define log types and the destination syslog server.
  • Enable secure SSH access to the SIEM server for administrative verification.
  • Verify the log feed by monitoring the live syslog file on the destination server.
3.1

Provision a Dedicated App Connector for Log Streaming

Create a separate connector path for Log Streaming Service.

  1. Open App Connector Groups in the Experience Center.
    Search menu → App Connector Groups
  2. Create an enabled App Connector Group named Log Streaming. Use the same remaining settings you used for the OnPrem group in Lab 2, then save it.
  1. Open the Corp: Log Streaming Connector VM. The connector displays an OAuth enrollment token when it first boots. If you need shell access, sign in with admin / zscaler and run:
    cat /etc/issue
  1. If you need a fresh token, regenerate it by stopping the connector, deleting the existing token files, and starting the service again:
    sudo systemctl stop zpa-connector
    sudo find /opt/zscaler/var/ -type f -name '*' -delete
    sudo systemctl start zpa-connector
  1. Open App Connectors in the Experience Center and select Add.
    Search menu → App Connectors
  2. Register the connector with
    SettingValue
    GroupLog Streaming
    Enrollment TokenEnter the token generated on the connector VM
    Signing CertificateConnector
    Select Save.
  3. Confirm the connector appears in the list. If the token is rejected or expired, generate a new token and retry.
✓
Expected result

A dedicated Log Streaming connector is enrolled and available for Log Streaming Service traffic.

3.2

Add a Log Receiver

Send ZPA User Activity events to the lab SIEM over syslog.

  1. Open Log Receivers in the Experience Center.
    Search menu → Log Receivers
  2. Select Add Log Receiver and configure the General settings:
    SettingValue
    NameSyslog-UserActivity
    Domain / IPsiem.patraining.safemarch.com
    TCP Port514
    App Connector GroupsLog Streaming
  3. Select Next. On Log Selection, set Log Type = User Activity and Log Template = CSV. Leave Log Stream Content at its defaults.
  1. On the Policy tab, leave the default settings and select Next.
  1. Review the configuration and select Save.
✓
Expected result

The Syslog-UserActivity receiver streams ZPA User Activity logs to the SIEM host on TCP/514 through the Log Streaming connector group.

3.3

Add SSH Access to the SIEM Server

Publish SSH access so you can verify the received logs.

  1. Open App Segments and create a new segment for SSH access to the SIEM server.
    Search menu → App Segments
  2. Configure the segment:
    SettingValue
    NameSSH to SIEM
    Applicationsiem.patraining.safemarch.com
    Default Port RangeSSH
    Segment GroupCorpApps
    Server GroupCorpServers
    Continue through the wizard and save the segment.
  1. Open the Access Policy editor—either from Edit Policy after saving the segment or by opening Access Policy directly.
    Search menu → Access Policy
  2. Create an Allow Access rule for the SSH to SIEM application and your lab user, then save it.
✓
Expected result

Your lab user is authorized to reach siem.patraining.safemarch.com over SSH through ZPA.

3.4

Verify the Log Feed

Connect to the SIEM and confirm User Activity records arrive.

  1. On Corp: Client PC 1, open Zscaler Client Connector and sign in with your assigned student account.
  2. Confirm that Internet Security and Private Access are available for the user.
  1. Open Command Prompt and connect to the SIEM host:
    ssh zscaler@siem.patraining.safemarch.com
    When prompted, enter Zscaler123! and accept the host key if required.
  2. Monitor the live syslog feed:
    tail -f /var/log/syslog
  3. Look for entries containing User Activity and zpa-lss. If no events appear, generate activity by refreshing the HVAC application from Lab 2.
i
Finish the SSH session

Press Ctrl+C to stop tail -f, then type exit to close SSH.

✓
Expected result

The SIEM host receives live User Activity events from ZPA Log Streaming Service.

✓

You have completed the activities defined for Configure Log Streaming.
